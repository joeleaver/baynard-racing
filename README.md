# Braynard Racing

An open-world kart racer starring barnyard animals, built on the [Playweft](https://github.com/joeleaver/playweft)
engine. It's Playweft's flagship game.

Early days: right now this repo holds the design ([`DESIGN.md`](./DESIGN.md)) and the art in progress
([`art/`](./art)). The game project itself comes when the engine has vehicle physics.
